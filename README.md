# MT4API-mtapi-java-

源码获取：ym7k.com/19730/

MTAPI（MT4 Java API）是用于 Java 程序对接 MetaTrader4 交易终端的中间接口源码，用来实现 Java 服务端和 MT4 客户端之间通信、行情读取、订单提交、账户信息查询，多用于外汇、差价合约程序化对接、资管风控、跟单系统、交易机器人后台。

> 
> 说明：这是**对接 MT4 终端的桥接 API**，不是 MT4 交易服务器（MT4 Server）源码，MT4 服务端本身迈达克官方并不对外开源。

## ✅ 技术架构

- 语言：Java（JDK8 / JDK11 为主）
- 通信底层：基于 MT4 原生套接字协议，或者依赖 MT4 的 DLL 桥接（mtapi.dll），Java 通过 JNA/JNI 调用
- 打包：Maven 项目，可打包 Jar、SpringBoot 集成到 Web 后台
- 配套：MT4 客户端（必须本地 / 服务器上运行 MT4 终端，API 依托 MT4 终端作为网关）
- 可选衍生：SpringBoot 封装版本，提供 Rest 接口，前端 H5 / 后台系统调用行情、订单接口

## ✅ 核心功能

1. **行情数据订阅**
获取品种实时 Bid/Ask 报价、K 线历史数据（M1/M5/M15/H1/H4/D1 等周期）、tick 实时数据流
2. **账户信息读取**
账户余额、净值、可用保证金、杠杆、账户名称、服务器、账户盈亏
3. **订单操作**
市价开仓、挂单（限价单、止损止盈）、修改订单、删除挂单、平仓、部分平仓
4. **订单 & 持仓查询**
持仓列表、历史订单、订单盈亏、订单注释、交易时间筛选
5. **消息推送回调**
行情变动回调、订单成交回调、账户变动通知，适合做跟单系统
6. **多账号管理**
支持同时连接多个 MT4 账号，多终端多路监听
7. **日志输出**
交易日志、行情日志、错误日志，方便排查掉单、断连问题

## ✅ 两种常见 Java 版 MTAPI 实现模式

1. **JNA 桥接 mtapi.dll（市面流传最多版本）**
Java → JNA 调用官方 / 第三方 mtapi.dll → MT4 终端。优点开发快；缺点依赖 Windows 环境（dll 是 Windows），Linux 服务器不能直接跑，需要 Windows 服务器挂 MT4 客户端。
2. **纯 Java 重写协议版（较少）**
Java 原生实现 MT4 通信协议，不依赖 dll；稳定性参差不齐，很多版本对新版本 MT4 兼容差、容易丢 tick、下单失败。

## ✅ 常见配套业务场景

- MT4 跟单交易系统（主账户跟单到多个子账户）
- 风控管理后台：监控所有账户爆仓、风控限额、禁止重仓
- 行情转发服务：把 MT4 行情推送到自己的 H5 盘面
- 资管系统、分仓管理系统、交易统计报表系统
- 自研交易信号平台

## ✅ 后台配套（很多打包版本附带）

- 账户管理：批量添加 MT4 账号、启停连接
- 风控规则配置：最大手数、最大亏损、禁止品种
- 交易记录查询、导出报表
- 断线重连自动重试机制

## ✅ 变现方式

1. 给资管团队部署 Java 版 MT4API 对接跟单、风控系统
2. 二次开发定制跟单平台、风控后台
3. 源码售卖、搭建调试服务
4. 封装对外行情 API 接口收费
